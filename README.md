# Ember Depths · 余烬地牢

一个使用 **Godot 4.4 + GDScript** 制作的俯视角动作肉鸽原型。所有像素场景、角色、图标及音效均由本工程代码生成，不需要额外购买美术资源。

## 运行

### 浏览器试玩与发布

工程包含 GitHub Pages 自动发布配置：推送到 `main` 后，GitHub Actions 会运行回归测试、导出 Godot 4.4.1 网页版并部署。仓库的 Settings → Pages → Source 需设为 **GitHub Actions**，发布网址可在 Actions 的部署结果中查看。

网页版使用单线程 WebAssembly，无需额外的跨域隔离响应头。请使用支持 WebGL 2 的现代电脑浏览器，首次加载完成后点击开始以启用音效。当前操作依赖键盘和鼠标，暂不提供手机触控操作。网页按 Esc 可能先退出全屏，窗口模式下也可使用商店内的退出按钮。

网页中文字体使用 ZCOOL KuaiLe（SIL Open Font License 1.1），随工程分发，许可见 `assets/fonts/ZCOOL-OFL.txt`。

本地网页导出（需要安装 Godot 4.4.1 Web 导出模板）：`godot --headless --path . --export-release Web build/web/index.html`。导出后通过 HTTP 静态服务器访问，不能直接双击 HTML 文件。

- 双击 `play.cmd`（随工程提供本地 Godot 工具时可直接运行）。
- 或用 Godot 4.4 / 更新版本导入 `project.godot`，按 F6/F5 运行。
- 窗口设计分辨率为 1280×800，窗口缩放时保持相同画布比例。
- 界面文字直接绘制到窗口，支持高 DPI、浏览器缩放和全屏切换；1280×800 仅用于布局坐标。HUD 不再先合成为贴图，避免二次缩放；小字最小 13，字体随窗口自动过采样，场景像素素材保留原有风格。

## 核心循环与通关目标

共 20 层，第 5 / 10 / 15 层为主题守门者，第 20 层为最终 Boss「余烬之源 · 终焉王」。击败最终房间全部敌人后进入通关画面，不会生成第 21 层。标题、楼层计数、Boss 名称和血条都显示当前目标。

入口安全房 → 探索房间 → 清场获得三选一祝福 → 出口房开启传送门 → 下一层。每层前两次普通战斗清场各奖励一次三选一；用完额度后的清场直接开门，出口仍正常开启。宝箱、诅咒和商店是独立的一次性额外机会；重复进入已清空房间不重复领奖。侧栏显示普通清场奖励额度。进入下一层恢复 20 生命，保留本局构筑。

每层 5–8 个房间，连接图保证连通，出口始终是最深的战斗房。特殊房随机分布在其余房间；前两层逐步引入，从第 3 层开始每层包含宝箱、诅咒、商店各一间。小地图用「宝 / 咒 / 商」标记，出口始终保留战斗。

| 房间 | 行为与奖励 |
|---|---|
| 战斗房 | 每层前两次普通清场各一次三选一，此后只开门；Boss 房计入普通额度，最终通关房直接结算 |
| 宝箱房 | 无敌人、无危险地形，中心按 E 获取一次额外三选一 |
| 诅咒房 | 所有敌人（含召唤/分裂子体）生命 +40%、伤害 +25%，清场连续选择两份祝福 |
| 商店房 | 中心按 E；被动祝福／主动技能／消耗品三页，TAB 切换。被动每店限一份，主动和消耗品可回访购买；所有价格每5层上涨25%，向上取整 |

击杀普通敌人获得 3 余烬、小怪子体 1 余烬、Boss 8 余烬。交易前检查余额，消费与奖励在同一流程完成，离开或重复进店不会免费领奖。

自然基础伤害随楼层增长：`25 × (1 + 0.09 × (楼层 - 1))`，伤害祝福在此基础上乘 `1.08^次数`，最后统一四舍五入，每局最多8次。基础伤害上限90（含永久加成），最终每段伤害上限140（含契约、药剂、剑气）。八次伤害祝福、无契约/永久加成时第1/5/10/20层伤害46/63/84/90。攻击冷却无论组合都至少0.30秒；不退誓言和低血狂舞只取一次×0.5，不再相乘。其他基础祝福：冷却缩短7%、移速+8、生命+12并回血12、剑距+8、击退+8。初始击退80，不中断敌人前摇/冲锋或重置冷却。主动技能、Boss生存预算与20层经济测试见 [PACING_ECONOMY.md](PACING_ECONOMY.md)。

六种行为祝福每局各限一次：挥剑剑气、闪避灼痕、击杀回血、低血狂舞、危险地形免疫和每层首次受伤免疫。另有三种每局限一次的高风险契约：

| 契约 | 收益 | 代价 |
|---|---|---|
| 碎玉之刃 | 全局伤害 ×1.4，后续伤害升级也受益 | 领取时生命上限 ×0.75，当前生命随上限收缩 |
| 不退誓言 | 有效攻击速度翻倍，可与低血狂舞叠乘 | 本局永久失去闪避，灼痕步因此无法触发 |
| 血焰契约 | 全局伤害 ×1.6 | 每次挥剑消耗 1 生命，可致死；不消耗 Ward，不能靠无敌帧规避 |

Boss 掉落 1 个永久余烬碎片，并为后续新局提供 +2 初始攻击力。碎片只保留在当前进程，尚未接入磁盘存档。击杀用的消费余烬每局清零，区别于跨局碎片。

### 主题 Boss

| 层数 | Boss | 技能与辨识 |
|---|---|---|
| 5 | 缠根古王（苔藓） | 枝角形象；藤蔓区先标记再伤害/减速、强化召唤、快速冲撞 |
| 10 | 熔心暴君（熔火） | 火角与熔核；七向熔火弹、快速冲撞、范围脉冲 |
| 15 | 霜冠守望者（冰霜） | 晶体王冠；减速冰面、减速扇形冰弹、范围脉冲 |
| 20 | 余烬之源 · 终焉王 | 独立光环；组合六技能，半血后施法间隔缩短，弹幕增至九发 |

普通 Boss 血量倍率5.5，最终Boss倍率9，并带显式最低HP预算（第5/10/15/20层至少3734/5600/7467/11667）。HP高于70%减伤15%，半血后减伤10%；攻击冷却1.6秒，半血二阶段1.1秒。受击不打断攻击或持续区域，撞墙仍眩晕0.6秒。主题技能数6/6/7，最终王17种。召唤预算和场上18只敌人上限保留；技能有预警，清场/换房清理。

### 事件音色

`sound_bank.gd` 为挥剑、命中、受击、闪避、奖励、清场、Boss 出场、施法、下潜、死亡、心跳、通关分别定义波形、扫频、起音和衰减包络。挥剑与闪避是滤波噪声，受击为下沉方波，命中和 Boss 出场为锯齿混合音，奖励/通关用多谐波铃音。音频在启动时生成并缓存，不在每次攻击时分配 PCM；噪声使用独立种子，不改变游戏 RNG。M 切换静音。

## 房型、主题与敌人

10 种房型使用独立数据表定义柱子、墙体、深渊、岩浆与尖刺。每层只从符合层级的房型池中选择；入口始终没有危险地形。

| 房型 | 出现层级 |
|---|---|
| 双柱小屋、四柱回廊、苔痕偏厅 | 1–3 |
| 折影长廊、双庭石室 | 2–6 |
| 尖刺试炼 | 3–6 |
| 裂隙石桥、熔池工坊 | 4+ |
| 断桥祭坛 | 5+ |
| 深渊熔核 | 6+ |

每层随机抽取苔藓、熔火或冰霜主题，统一更换地板、墙面、灯光、纹样与漂浮碎片色板。主题只改变美术，不改变危险地形规则；岩浆始终使用醒目的橙红色。

深渊不可通行，岩浆造成持续伤害，尖刺先预警再周期性升起。闪避可穿越岩浆/尖刺而不受伤，但不能穿墙或跨越深渊。出生点和敌人正常寻路都避开危险地形。中央通路、门口落点和传送门始终连通。

| 敌人 | 解锁 | 行为 |
|---|---|---|
| 掷火者 | 1+ | 保持距离，瞄准前摇后投掷火弹；火弹被墙壁拦截 |
| 裂角冲锋者 | 1+ | 直线预警后沿锁定方向冲锋，撞墙停止 |
| 唤灵祭司 | 2+ | 前摇后召唤两个小怪；每只最多召唤四个 |
| 爆焰虫 | 2+ | 靠近后引爆，爆炸范围提前显示，可以提前击杀 |
| 裂生黏灵 | 3+ | 死亡后分裂为两个小黏灵，子体不再分裂 |

五种敌人的生命、速度、伤害独立配置，第一层起的基础生命和伤害已提高。当前 20 层战役内，普通敌人生命按每层 1.18 倍增长；保留的 24 层后软化公式仅供将来扩展使用。房间最多同时存在 18 个敌人；召唤和分裂遵守上限。分裂子体先加入存活列表，再检查父体死亡，防止提前清场。清场和换房间会清除残留火弹。

受击时屏幕边缘短暂泛红；生命不高于 30% 时，有红色脉冲、心跳音效和生命垂危提示。M 可关闭音效。

## 代码导览

- `scripts/game.gd`：本局状态、每层清场奖励额度、商店、Boss、永久余烬、房间切换、敌人生成、层级推进、音效。
- `scripts/room_generator.gd`：随机房间连接图，独立于表现层。
- `scripts/room_catalog.gd`：10 种房型、按层级筛选的房型池、三种主题色板。
- `scripts/room.gd`：瓦片、危险地形、门、碰撞、火光与敌人 BFS 追踪方向。
- `scripts/player.gd`：WASD、扇形近战、剑气、闪避轨迹、行为祝福、受伤。
- `scripts/enemy_catalog.gd`：五种敌人的解锁层级、生命、速度、伤害、前摇与色板。
- `scripts/enemy.gd`：追踪、分离、投掷、冲锋、召唤、自爆、分裂与攻击前摇。
- `scripts/boss_module.gd` / `boss_zone.gd`：主题 Boss 技能表、独立形象、弹幕与预警区域。
- `scripts/sound_bank.gd`：合成音色预设、波形与包络、音频流缓存。
- `scripts/projectile.gd`：火弹移动、轨迹与连续碰撞检测。
- `scripts/hud.gd`：界面、小地图、三选一、暂停与死亡界面。
- `scripts/pixel_art.gd`：原创像素角色绘制。
- `scripts/effects.gd`：粒子、飘字。

祝福参数在 `game.gd` 的 `UPGRADES`、`new_run()` 中。扩展房间形态、层级池或主题，修改 `room_catalog.gd` 即可；敌人数值在 `enemy_catalog.gd` 中。房型坐标使用 32 像素瓦片单位，新增地形时请保留中间安全十字通道。角色绘制在 `pixel_art.gd`。

## 验证

### 渲染缓存

房间的地板、墙体、危险地形底图、纹样、门和边缘阴影合成到独立的 SubViewport，仅在配置房间或门锁状态改变时使用 `UPDATE_ONCE` 更新。缓存绘制不调用 RNG，保持同 seed 的装饰和后续出生点序列。火焰、余烬、传送门和危险地形动画在独立节点绘制；火把的多层光晕也复用离屏纹理，通过缩放保留脉动。

HUD 通过 `hud_changed`、`stats_changed` 和房间的 `presentation_changed` 信号失效，同帧事件合并一次更新，在原生窗口画布中保留绘制命令；文字不经过中间贴图。时间每 0.5 秒采样，仅显示的秒数变化时刷新。悬停和传送门提示只在状态切换时刷新；准星只移动小节点，受击红边和转场独立绘制。StyleBoxFlat 在 HUD 初始化时预热并复用。工程限制为最高 60 FPS。

`tests/render_cache.gd` 可在 headless 下检查缓存失效、RNG、HUD 信号、计时和样式复用；去掉 `--headless` 可使用真实渲染器对比房间静态几何直接绘制与纹理缓存的提交数量。两种情况下 HUD 文字都直接绘制到窗口：

```text
tools/Godot_v4.4.1-stable_win64_console.exe --path . --rendering-method gl_compatibility --script res://tests/render_cache.gd
```

测试输出暂停与静止游玩场景的 draw calls 和图元数量，实际数值随窗口大小、字体和平台变化。这是同场景绕过房间纹理缓存的对照，保留同样的 HUD 与动态层；不代表完整历史版本的 GPU 性能。重建缓存的帧、战斗、岩浆和传送门动画仍有额外绘制成本。测试只验证绘制提交量，未测 GPU 功耗或频率。

```text
tools/Godot_v4.4.1-stable_win64_console.exe --headless --path . --editor --quit
tools/Godot_v4.4.1-stable_win64_console.exe --headless --path . --script res://tests/smoke.gd
tools/Godot_v4.4.1-stable_win64_console.exe --headless --path . --script res://tests/input_smoke.gd
tools/Godot_v4.4.1-stable_win64_console.exe --headless --path . --script res://tests/expansion.gd
tools/Godot_v4.4.1-stable_win64_console.exe --headless --path . --script res://tests/render_cache.gd
tools/Godot_v4.4.1-stable_win64_console.exe --headless --path . --script res://tests/campaign.gd
```

测试涵盖连接图连通性、门的双向一致性、攻击方向判定、每层普通清场奖励额度、奖励不重复、奖励只领取一次、层级保留与死亡重置。

输入检查通过 Godot 事件分发验证 Enter 开局、WASD 移动、鼠标攻击、空格闪避、暂停继续、数字键选奖励以及死亡后重开。`tests/visual.gd` 用实际渲染器生成标题、战斗和奖励截图，分别保存在 `preview-title.png`、`preview-game.png`、`preview-reward.png`。

扩展测试验证 10 种房型中所有安全地块及门口的连通性、360 组层级池抽样、危险地形、五种敌人行为、火弹碰撞、分裂与清场顺序、先原地再移动闪避、攻速到顶后的 80 次奖励抽取。三主题预览保存在 `preview-theme-moss.png`、`preview-theme-lava.png`、`preview-theme-frost.png`。

完整探索一层最多两次普通清场祝福、诅咒两次、宝箱一次，商店还可购买一次；最终房直接通关。不领奖的后续普通战斗仍提供余烬。随机池中的伤害卡会显示已叠次数，旧商店卡若已失效则拒绝扣款。
